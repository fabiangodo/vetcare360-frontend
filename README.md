💻 VetCare 360 - Single Page Application Frontend (React + TypeScript)📌 Contexto General del ProyectoVetCare 360 es una solución web integral para la gestión de clínicas veterinarias. Permite la interacción diferenciada según el perfil del usuario (Administrador, Veterinario y Cliente). Ofrece una interfaz moderna y reactiva, combinando persistencia directa en la nube y un flujo de backend desacoplado bajo una arquitectura Serverless.🛠️ Tecnologías UtilizadasFramework & Tooling: React 18 + TypeScript + ViteDiseño & Estilos: Tailwind CSS, Lucide React (Iconografía)Autenticación & Seguridad: AWS Cognito (us-east-1)Backend & Integración Serverless: AWS API Gateway + AWS Lambda (Node.js)Base de Datos & Persistencia: Supabase (PostgreSQL) con API REST y JWT de accesoHosting / Despliegue Continuo: Vercel (CI/CD sincronizado con GitHub)☁️ Arquitectura Serverless y Flujo de DatosEl sistema implementa un patrón desacoplado para el procesamiento seguro de acciones y órdenes en la plataforma.Plaintext[ Cliente Web (React / Vercel) ]

🔄 Flujo de Transmisión de Datos Paso a Paso:Acción del Usuario y Autenticación:Al interactuar con la interfaz (por ejemplo, al hacer clic en un botón para enviar una solicitud, registrar información o procesar una orden), la aplicación empaqueta los datos y adjunta el IdToken (JWT) emitido por AWS Cognito en la cabecera Authorization: Bearer <TOKEN>.Recepción y Validación en AWS API Gateway:La petición HTTP se envía hacia el endpoint expuesto en AWS API Gateway. El Cognito Authorizer valida la firma y vigencia del token. Si la solicitud es autorizada, el API Gateway delega el evento e invoca automáticamente la función AWS Lambda.Procesamiento en AWS Lambda:La función AWS Lambda procesa el payload recibido, ejecuta la lógica de negocio requerida y se conecta de forma segura con la API REST de Supabase utilizando credenciales protegidas en sus variables de entorno.Persistencia y Respuesta:La Lambda realiza la escritura/actualización en la base de datos PostgreSQL, genera los registros de auditoría/informes correspondientes y retorna una respuesta 200 OK (con cabeceras CORS). El frontend recibe la confirmación y actualiza la interfaz de usuario en tiempo real.🔍 Módulos e Integración de la Aplicación1.
